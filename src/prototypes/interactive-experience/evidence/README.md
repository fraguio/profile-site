# Evidencia de Impeccable

Cada sesión conserva aquí un manifiesto Markdown y los outputs JSON del detector. Los nombres incluyen la sesión, la variante y el target para que desktop, mobile y código puedan revisarse sin confundir las tres direcciones.

Los manifiestos registran el comando o prompt exacto, la URL, el viewport, la fecha, las rutas de sus informes y el resultado. Esta evidencia documenta observaciones del experimento; no sustituye el brief ni define un sistema visual de producción.
