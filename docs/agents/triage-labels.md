# Etiquetas de triage

Las skills hablan en términos de cinco roles canónicos de triage. Este archivo mapea esos roles a las etiquetas reales usadas en el issue tracker de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Un maintainer debe evaluar este issue |
| `needs-info` | `needs-info` | Esperando más información del reporter |
| `ready-for-agent` | `ready-for-agent` | Completamente especificado, listo para un agente AFK |
| `ready-for-human` | `ready-for-human` | Requiere implementación humana |
| `wontfix` | `wontfix` | No se va a accionar |

Cuando una skill mencione un rol, por ejemplo "apply the AFK-ready triage label", usa la etiqueta correspondiente de esta tabla.

Edita la columna derecha para ajustarla al vocabulario real que uses.
